# HEM Client

Vue 3 storefront and admin interface for the HEM fashion ecommerce project.

Key folders:

- `src/views`: route-level pages.
- `src/components`: reusable UI grouped by domain.
- `src/services`: feature API modules.
- `src/stores`: lightweight store facades.
- `src/composables`: reusable feature hooks.
- `src/styles`: shared tokens, utilities, and animation helpers.
